# Phishing : identifier les arnaques et protéger ses données

<div class="flex justify-center mb-8">
  {{< img src="/images/securite_phishing.png" alt="Phishing Alert" class="max-w-full md:max-w-lg rounded-lg shadow-lg border border-gray-200 dark:border-gray-700" >}}
</div>

Le phishing (hameçonnage) est l'art de la tromperie numérique. L'objectif ? Vous faire croire que vous parlez à votre banque, La Poste ou Netflix pour vous voler vos mots de passe.

<div class="bg-blue-50 dark:bg-blue-900/20 border-l-4 border-blue-500 p-4 mb-6 rounded-r-lg">
  <div class="flex items-start">
    <div class="flex-shrink-0">

    </div>
    <div class="ml-3">
      <p class="text-blue-800 dark:text-blue-200 font-medium">Le mécanisme du piège</p>
      <ol class="list-decimal list-inside text-blue-700 dark:text-blue-300 text-sm mt-1">
        <li><strong>L'appât</strong> : Un mail urgent (Colis bloqué, Facture impayée).</li>
        <li><strong>L'action</strong> : Vous cliquez sur un lien.</li>
        <li><strong>La copie</strong> : Vous arrivez sur un fausse site (copie parfaite de l'officiel).</li>
        <li><strong>Le vol</strong> : Vous tapez votre mot de passe, les pirates le récupèrent.</li>
      </ol>

## Techniques pour repérer une arnaque

1.  **L'Expéditeur** : Regardez l'adresse mail réelle. `support@netflix-security-update.com` n'est PAS Netflix.
2.  **L'Urgence** : Les pirates veulent vous faire paniquer ("Compte supprimé dans 24h"). Une vraie banque ne menace jamais par mail.
3.  **L'URL** : Survolez le lien sans cliquer. Si ça ne pointe pas vers le site officiel exact, c'est un piège.
