# Ransomware : comment se protéger et réagir en cas d'attaque

<div class="flex justify-center mb-8">
  {{< img src="/images/securite_ransomware.png" alt="Ransomware Attack Concept" class="max-w-full md:max-w-lg rounded-lg shadow-lg border border-gray-200 dark:border-gray-700" >}}

La menace des **ransomwares** (ou rançongiciels) est l'une des plus préoccupantes en cybersécurité. Ces logiciels malveillants prennent en otage vos données personnelles ou professionnelles en les chiffrant, puis exigent une rançon pour vous restituer l'accès.

  <div class="flex items-start">

    </div>
    <div class="ml-3">
      <p class="text-blue-800 dark:text-blue-200 font-medium">Définition</p>
      <p class="text-blue-700 dark:text-blue-300 text-sm mt-1">Un ransomware est un programme qui chiffre vos fichiers. Sans la clé (détenue par les pirates), vos fichiers sont techniquement irrécupérables... sauf si vous avez une sauvegarde.</p>
    </div>
  </div>
</div>

## Vecteurs d'infection : Comment il entre ?

L'infection survient généralement par ces portes d'entrée :
1.  **Le phishing** : Pièce jointe piégée (fausse facture PDF/Word).
2.  **Sites infectés** : Téléchargement automatique ("drive-by download") en visitant un site web compromis.
3.  **Logiciels piratés** : Les "cracks" de logiciels contiennent souvent des malwares.

## Mesures préventives : La Sauvegarde est Roi

La prévention est votre meilleure défense. Une stratégie efficace repose sur deux piliers.

### 1. La sauvegarde (backup) systématique

  <div class="flex items-start">

      <p class="text-green-700 dark:text-green-300 text-sm mt-1">Ayez toujours une copie de vos données sur un <strong>disque dur externe DÉBRANCHÉ</strong> quand vous ne l'utilisez pas. Si le disque est connecté lors de l'attaque, il sera chiffré aussi !</p>
    </div>
  </div>

### 2. Les logiciels de protection
*   Utilisez un antivirus avec **module anti-ransomware**.
*   Gardez Windows et vos logiciels à jour.

## Que faire si vous êtes victime d'un ransomware ?

Si le message de rançon s'affiche... **PAS DE PANIQUE, MAIS AGISSEZ VITE**.

  <div class="flex items-start">
    <div class="flex-shrink-0">

      <ol class="list-decimal list-inside text-red-700 dark:text-red-300 text-sm mt-1">
        <li><strong>DÉBRANCHEZ TOUT</strong> : Câble réseau, Wi-Fi, disques externes. Isolez la machine infectée.</li>
        <li><strong>NE PAYEZ PAS</strong> : Payer finance les criminels et ne garantit rien.</li>
        <li><strong>Identifiez</strong> : Utilisez le site <em>No More Ransom</em> pour voir si un outil de déchiffrement gratuit existe.</li>
        <li><strong>Restaurez</strong> : Formatez le PC et restaurez votre sauvegarde saine.</li>
      </ol>

**Conclusion** : Face au ransomware, la sauvegarde est votre assurance-vie. Préparez-vous avant l'attaque.
