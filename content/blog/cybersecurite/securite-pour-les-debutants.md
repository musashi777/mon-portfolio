## 1. Les Mots de Passe : Votre première défense

<div class="bg-yellow-50 dark:bg-yellow-900/20 border-l-4 border-yellow-500 p-4 mb-6 rounded-r-lg">
  <div class="flex items-start">
    <div class="flex-shrink-0">
      <i class="fas fa-key text-yellow-500 text-lg mt-1"></i>
    </div>
    <div class="ml-3">
      <p class="text-yellow-800 dark:text-yellow-200 font-medium">L'erreur classique</p>
      <p class="text-yellow-700 dark:text-yellow-300 text-sm mt-1">Utiliser le même mot de passe partout (comme "123456" ou le nom de son chien). Si un site est piraté, tous vos comptes le sont !</p>
    </div>
  </div>
</div>

**La solution facile** : Utilisez des phrases. Au lieu de `Snoopy`, écrivez `J'aime_Promener_Snoopy_Le_Matin!`. C'est plus facile à retenir pour vous, et très dur à deviner pour un robot.
Mieux encore : utilisez un **Gestionnaire de mots de passe** (coffre-fort numérique).

## 2. Les Mises à jour : Ne cliquez pas sur "Plus tard"

Quand Windows ou votre téléphone vous demande de faire une mise à jour, faites-le. Ce sont souvent des "vaccins" contre les nouveaux virus.

## 3. L'Antivirus : Votre garde du corps

Sur Windows 10 et 11, l'antivirus intégré (**Windows Defender**) est excellent. Vérifiez juste qu'il est activé (petit bouclier vert dans la barre des tâches). Pas besoin de payer cher pour être protégé si vous débutez.

## 4. Le Phishing : Ne mordez pas à l'hameçon

Si vous recevez un mail qui dit : "URGENT : Votre compte est bloqué, cliquez ici", c'est une arnaque.
*   **Regardez l'adresse de l'expéditeur** (est-ce vraiment `@impots.gouv.fr` ou `@impots-info-bizarre.com` ?).
*   **Ne cliquez jamais** dans le doute. Allez directement sur le site officiel via Google.
